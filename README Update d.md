## ✨ What is ACUN?

ACUN is a **practical, drop-in replacement** for standard DP-SGD that **jointly optimizes the clipping threshold and noise scale** online. It maintains a differentially private estimate of the median gradient norm and derives a closed-form noise multiplier that minimizes a local quadratic approximation of excess risk.

| Component | Description |
|-----------|-------------|
| Private median estimator | Exponential mechanism on a geometric histogram of gradient norms |
| Utility-aware noise | Closed-form \(C_t^\star, \sigma_t^\star\) from local excess-risk proxy |
| One extra hyper-parameter | Fraction of privacy budget for the median (default **5%**) |
| Integration | Works with Opacus + Hugging Face + PEFT (LoRA / QLoRA) |

## 🧠 Core API

```python
from acun import ACUNPrivacyEngine

engine = ACUNPrivacyEngine(
    module=model,
    batch_size=batch_size,
    sample_size=len(train_dataset),
    epochs=epochs,
    target_epsilon=3.0,
    target_delta=1e-5,
    median_budget_fraction=0.05,   # only extra hyper-parameter
)

model, optimizer, train_loader = engine.make_private(
    module=model,
    optimizer=optimizer,
    data_loader=train_loader,
    max_grad_norm=1.0,
)
```

ACUN automatically:
1. Maintains a **private median** of per-example gradient norms  
2. Allocates remaining Rényi budget  
3. Sets optimal \(C_t^\star\) and \(\sigma_t^\star\) via the closed-form solution (Eq. 5 in the paper)

## 🔬 Method Overview (short)

At each step \(t\):

1. **Private median** of gradient norms via exponential mechanism on a geometric histogram.  
2. Remaining Rényi budget \(\rho_t\) is read from the accountant.  
3. Closed-form solution of the local excess-risk objective:

\[
C_t^\star = \hat{m}_t \Bigl(1 + \sqrt{\tfrac{2\rho_t B^2}{\eta L d}}\Bigr), \qquad
\sigma_t^\star = \frac{\sqrt{2\rho_t}}{C_t^\star / B}
\]

This yields both **formal \((\varepsilon,\delta)\)-DP** and a high-probability excess-risk bound (Theorems 1 & 2 in the paper).
